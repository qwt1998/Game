# 午高峰跑单

外卖骑手题材的网页小游戏。11:00 到 13:30 的午高峰里，骑电动车在城里接单、送餐、换电，躲开车流和交警，看能跑多少钱。

## 怎么玩

- **在线玩（可以直接分享）**：<https://qwt1998.github.io/Game/> ，任何人点开就能玩，不用登录
- **3D 试玩版**：<https://qwt1998.github.io/Game/3d.html> ，同一个游戏，地图换成斜着看的 3D 城市；成绩和正式版记在一起
- **Claude 上的版本**：<https://claude.ai/artifact/FTjmnJ6vQMNN4nr5QSYrYA>（默认只有自己能打开）
- **本地玩**：下载 `index.html`，双击用浏览器打开就行，不需要安装任何东西

每次把新版本推到 `main` 分支，在线链接会在 1～2 分钟内自动更新。

电脑：方向键 / WASD 转向，空格刹车，P 暂停，M 静音
手机：在地图上滑动转向，或用下方按键

箱子里有单时，路上会画一条彩色导航线，带你去最快要超时的那一单；导航线默认打开，不想要的话，在开始页或暂停页把"导航线"关掉，下次会记住。

### 放到手机桌面

用手机打开在线链接后，可以把它添加到桌面，桌面上会出现"跑单王"图标，点开就是全屏游戏，玩过一次后断网也能打开：

- **安卓**：浏览器弹出"安装"时点安装；没弹就在浏览器菜单里选"添加到主屏幕"
- **苹果**：用 Safari 打开，点底部"分享"按钮，选"添加到主屏幕"
- **微信里点开的**：先点右上角"…"选"在浏览器打开"，再按上面的方法添加

## 文件说明

整个游戏只有一个文件：`index.html`。地图、车辆、交警、计分、背景音乐和音效都写在里面，没有图片或音频文件，声音是浏览器现场合成的。

另外几个文件只用来"放到手机桌面"：`manifest.webmanifest`（桌面名字和图标）、`sw.js`（离线也能打开）、`icons/`（桌面图标，`icons/icon.html` 是画图标的代码，用浏览器打开能看到预览）。

## 怎么继续改

直接告诉 AI 想改什么就行，比如"把交警罚款改成 20 块""加一个下雨天路滑的设定"。

- **在 Claude 对话里改**：把这个仓库交给 Claude，说清楚要改什么，改完让它推回仓库，同时更新上面那个 Claude 链接
- **用 Claude Code 或 Codex 改**：在本仓库里打开就能改，`AGENTS.md` 里写了给 AI 看的开发说明

每次改动都会留下版本记录，改坏了可以回到任意一个旧版本。

## 存档说明

开始页可以填骑手名字（不填就用默认的"骑手 + 四位数"），点"换人"能在同一台设备上切换或新建骑手。每个名字各记各的：最好成绩、跑了几局、累计收入、准时率、最近 10 局。

这些记录和声音设置都保存在你当前使用的浏览器里，换设备、换浏览器或清除浏览器数据后会重置。iPhone 上从桌面图标打开和在 Safari 里打开，记录是分开的。

## 分享给朋友

开始页、结算页和对战房间里都有"分享"按钮，点了会画出一张海报（游戏画、成绩或房间号、二维码）：

- **发给好友，对方一点就开**：在微信里，按提示点右上角"…"选"发送给朋友"，对方收到一张写着邀请的卡片；在手机浏览器里会直接弹出分享菜单；电脑上会复制邀请文字
- **海报**：长按保存或直接发给朋友、发朋友圈，朋友长按图里的二维码就能直接开玩
- **对战邀请**：从对战房间分享出去的卡片和二维码都带着房间号，朋友打开就自动申请加入，你点"同意"就能开打
- 网址发到 QQ、iPhone 短信、飞书这些地方，会显示成带大图和标题的卡片（大图是 `icons/share.jpg`）

## 和朋友对战

开始页点"和朋友对战"：一个人点"开房间"，把 4 位房间号发给朋友；朋友点"和朋友对战"，输入房间号申请加入，房主点"同意"他才进得来（不认识的人乱输号码也进不来）。两个人都点"准备"，倒数 3 秒后同时开跑，地图上绿色的车就是对方，屏幕上方能看到对方赚了多少。

- 两个人看到的是同一批单：同样的店、同样的配送费、同一时刻出现，谁先骑到就是谁的，另一边的这一单会消失
- 13:30 收工时比收入，多的赢；提前收工或中途离开的一方算输
- 两个人各用各的手机或电脑，正式版和 3D 试玩版之间也能对战
- 对战中时间不会停：按暂停或切出去，对方照样在跑
- 网络断了会自己重连；一方离开超过 30 秒，另一方接着跑完
- 对战的成绩也照常记进自己的记录和排行榜
- 只在 <https://qwt1998.github.io/Game/> 上能对战，Claude 上的版本没有这个按钮

## 排行榜

每局结束后，成绩会自动传到排行榜（按每个骑手的历史最好成绩排），开始页和结算页都能点进去看前 20 名和自己排第几。名字是公开的，提醒大家别填真名。连不上排行榜时游戏照常能玩，成绩下次打开自动补传。

排行榜和对战程序在 `server/` 文件夹里，跑在自己的服务器上。在服务器控制台里：

- 安装或更新：`curl -fsSL https://qwt1998.github.io/Game/server/install.sh | bash`
- 看前 50 名：`paodan list`
- 把造假的成绩藏起来：`paodan hide 名字`（恢复用 `paodan unhide 名字`）
